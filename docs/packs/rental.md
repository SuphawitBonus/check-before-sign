# ข้อมูลกฎหมายและเกณฑ์การตรวจ: สัญญาเช่าที่อยู่อาศัย (Rental Pack)

## 1. ที่มาและสถานะทางกฎหมาย (Legal Basis & Status)

### 1.1 ประกาศที่ใช้บังคับในปัจจุบัน
- **ชื่อประกาศทางการ:** ประกาศคณะกรรมการว่าด้วยสัญญา เรื่อง ให้ธุรกิจการให้เช่าอาคารเพื่ออยู่อาศัยเป็นธุรกิจที่ควบคุมสัญญา พ.ศ. ๒๕๖๒ และฉบับปรับปรุง พ.ศ. ๒๕๖๘
- **ผู้ออกประกาศ:** คณะกรรมการว่าด้วยสัญญา สำนักงานคณะกรรมการคุ้มครองผู้บริโภค (สคบ.) สำนักนายกรัฐมนตรี
- **อำนาจตามกฎหมาย:** มาตรา ๓๕ ทวิ แห่งพระราชบัญญัติคุ้มครองผู้บริโภค พ.ศ. ๒๕๒๒ ซึ่งแก้ไขเพิ่มเติมโดยพระราชบัญญัติคุ้มครองผู้บริโภค (ฉบับที่ ๒) พ.ศ. ๒๕๔๑

### 1.2 ข้อมูลการประกาศในราชกิจจานุเบกษา
1. **ประกาศคณะกรรมการว่าด้วยสัญญา พ.ศ. ๒๕๖๒:**
   - ราชกิจจานุเบกษา: เล่ม ๑๓๖ ตอนพิเศษ ๒๗๐ ง หน้า ๕๑
   - วันที่ประกาศ: ๓๑ ตุลาคม ๒๕๖๒
   - วันที่มีผลใช้บังคับ: ๓๐ มกราคม ๒๕๖๓ (พ้นกำหนด ๙๐ วันนับแต่วันประกาศ)
   - แหล่งอ้างอิง: [ราชกิจจานุเบกษา 2562](https://ratchakitcha.soc.go.th/documents/72766.pdf)
2. **ประกาศคณะกรรมการว่าด้วยสัญญา พ.ศ. ๒๕๖๘ (ฉบับปรับปรุงล่าสุด):**
   - ราชกิจจานุเบกษา: เล่ม ๑๔๒ ตอนพิเศษ ๒๑๑ ง หน้า ๘๐
   - วันที่ประกาศ: ๖ มิถุนายน ๒๕๖๘
   - วันที่มีผลใช้บังคับ: ๔ กันยายน ๒๕๖๘
   - แหล่งอ้างอิง: สำนักงานคณะกรรมการคุ้มครองผู้บริโภค (สคบ.) [www.ocpb.go.th](https://www.ocpb.go.th) / [ratchakitcha.soc.go.th](https://ratchakitcha.soc.go.th/documents/72766.pdf)

## 2. ขอบเขตการบังคับใช้ (Jurisdiction & Scope)

### 2.1 ใครอยู่ในขอบเขตที่กฎหมายคุ้มครอง (In-Scope)
กฎหมายนี้ใช้บังคับเมื่อเข้าเงื่อนไขครบทุกข้อดังต่อไปนี้:
1. **ผู้เช่า (Lessee):** ต้องเป็น **"บุคคลธรรมดา"** (ไม่ใช่นิติบุคคล)
2. **วัตถุประสงค์ในการเช่า:** เช่าอาคารเพื่อใช้เป็น **"ที่อยู่อาศัย"** เท่านั้น (ไม่ใช่เพื่อพาณิชย์ สำนักงาน หรือเปิดร้านค้า)
3. **ผู้ให้เช่า (Lessor / ผู้ประกอบธุรกิจ):** เป็นผู้ประกอบธุรกิจให้เช่าอาคารเพื่ออยู่อาศัย โดยมีเกณฑ์จำนวนสถานที่ให้เช่า:
   - **ฉบับ พ.ศ. ๒๕๖๒:** มีสถานที่ที่จัดแบ่งให้เช่าตั้งแต่ **๕ หน่วยขึ้นไป**
   - **ฉบับปรับปรุง พ.ศ. ๒๕๖๘:** ขยายความคุ้มครองลงมาครอบคลุมผู้ให้เช่าที่มีสถานที่จัดแบ่งให้เช่าตั้งแต่ **๓ หน่วยขึ้นไป** (ไม่ว่าจะอยู่ในอาคารเดียวกันหรือหลายอาคารรวมกัน)
4. **ประเภทอาคารที่ครอบคลุม:**
   - ห้องพักในอพาร์ตเมนต์
   - ห้องชุดในอาคารชุด (คอนโดมิเนียม) ที่เจ้าของนำมาปล่อยเช่าโดยมีรวมกันตั้งแต่ ๓–๕ หน่วยขึ้นไป
   - บ้านเช่า (บ้านเดี่ยว, ทาวน์เฮาส์) ที่นำมาปล่อยเช่าตั้งแต่ ๓–๕ หน่วยขึ้นไป
   - หอพักเอกชนทั่วไปที่ไม่ได้จดทะเบียนตาม พ.ร.บ. หอพัก พ.ศ. ๒๕๕๘

### 2.2 สิ่งที่ไม่ครอบคลุม (Out of Scope / Exclusions)
1. **หอพักตามกฎหมายว่าด้วยหอพัก (พ.ร.บ. หอพัก พ.ศ. ๒๕๕๘):**
   - หอพักสถานศึกษา (หอในมหาวิทยาลัย/โรงเรียน) หรือหอพักเอกชนที่จดทะเบียนอยู่ภายใต้การกำกับของกระทรวงการพัฒนาสังคมและความมั่นคงของมนุษย์ (พม.)
2. **โรงแรมตามกฎหมายว่าด้วยโรงแรม (พ.ร.บ. โรงแรม พ.ศ. ๒๕๔๗):**
   - สถานที่พักที่เปิดให้บริการรายวันและได้รับใบอนุญาตประกอบธุรกิจโรงแรม
3. **การเช่าโดยผู้ให้เช่ารายย่อยที่มีไม่ถึงเกณฑ์:**
   - เจ้าของบ้านหรือเจ้าของคอนโดปล่อยเช่าเพียง ๑ หรือ ๒ ห้อง/หลัง (ไม่อยู่ในนิยามผู้ประกอบธุรกิจที่ควบคุมสัญญาของ สคบ. แต่อยู่ใต้ประมวลกฎหมายแพ่งและพาณิชย์ บรรพ ๓ ลักษณะเช่าทรัพย์)
4. **การเช่าเพื่อประกอบธุรกิจหรือการค้า:**
   - การเช่าพื้นที่เปิดหน้าร้าน ออฟฟิศ คาเฟ่ โกดังสินค้า หรือการเช่าในนามบริษัท/นิติบุคคล

## 3. สาระสำคัญของข้อห้ามและข้อกำหนดตามตัวบท (Core Rules)

| ข้อ/ประเด็น | สาระสำคัญตามตัวบทกฎหมาย | ผลเมื่อสัญญาเขียนขัดแย้ง |
| :--- | :--- | :--- |
| **๑. เงินประกัน (Security Deposit)** | เรียกเก็บได้ไม่เกินอัตราค่าเช่าตามที่กฎหมายกำหนด (ฉบับ ๒๕๖๒ กำหนดไม่เกิน ๑ เดือน, ฉบับ ๒๕๖๘ กำหนดเงินประกันและค่าเช่าล่วงหน้ารวมกันไม่เกิน ๓ เดือน โดยค่าเช่าล่วงหน้าไม่เกิน ๑ เดือน) | ขัดต่อประกาศ สัญญาตกเป็นโมฆะในส่วนที่เกิน |
| **๒. ค่าเช่าล่วงหน้า (Advance Rent)** | เรียกเก็บได้ไม่เกิน **๑ เดือน** ของอัตราค่าเช่ารายเดือน | ขัดต่อประกาศ |
| **๓. ค่าไฟฟ้า (Electricity Tariff)** | ห้ามเรียกเก็บเกินกว่าอัตราที่การไฟฟ้านครหลวง (กฟน.) หรือการไฟฟ้าส่วนภูมิภาค (กฟภ.) เรียกเก็บจริงจากผู้ประกอบธุรกิจ (ห้ามบวกกำไรส่วนต่าง) | ขัดต่อประกาศ ผู้ให้เช่าไม่มีสิทธิเรียกเก็บส่วนเกิน |
| **๔. ค่าน้ำประปา (Water Tariff)** | ห้ามเรียกเก็บเกินกว่าอัตราที่การประปานครหลวง (กปน.) หรือการประปาส่วนภูมิภาค (กปภ.) เรียกเก็บจริงจากผู้ประกอบธุรกิจ (ห้ามบวกกำไรส่วนต่าง) | ขัดต่อประกาศ ผู้ให้เช่าไม่มีสิทธิเรียกเก็บส่วนเกิน |
| **๕. การคืนเงินประกัน (Deposit Return)** | เมื่อสัญญาเช่าสิ้นสุดและผู้เช่าส่งมอบห้องคืนโดยไม่มีความเสียหาย ต้องคืนเงินประกันให้แก่ผู้เช่าภายใน ๗ วัน (ฉบับ ๒๕๖๘) หรือทันที/ไม่เกินกำหนด | ขัดต่อประกาศ ห้ามตั้งเงื่อนไขยื้อเกินกำหนด |
| **๖. การริบเงินประกัน (Forfeiture of Deposit)** | ห้ามมีข้อสัญญาให้ริบเงินประกันทั้งหมดโดยไม่มีความเสียหายจริง หรือริบเงินประกันกรณีผู้เช่าบอกเลิกสัญญาก่อนกำหนดโดยผู้ให้เช่าไม่ได้รับความเสียหายตามจริง | ข้อสัญญาตกเป็นโมฆะ ต้องคืนเงินประกันส่วนที่เหลือ |
| **๗. สิทธิการบอกเลิกสัญญาของผู้เช่า (Tenant Termination)** | ผู้เช่ามีสิทธิบอกเลิกสัญญาก่อนครบกำหนดได้ หากเช่ามาแล้วไม่น้อยกว่ากึ่งหนึ่งของระยะเวลาตามสัญญา โดยต้องบอกกล่าวล่วงหน้าเป็นหนังสือไม่น้อยกว่า ๓๐ วัน และไม่ผิดนัดชำระค่าเช่า | สัญญาที่ห้ามผู้เช่าบอกเลิกสัญญาไม่ว่ากรณีใด ๆ ถือว่าขัดต่อประกาศ |
| **๘. การบอกเลิกสัญญาของผู้ให้เช่า (Lessor Termination)** | ผู้ให้เช่าจะบอกเลิกสัญญาได้ต้องมีหนังสือบอกกล่าวให้ผู้เช่าปฏิบัติตามสัญญาภายในเวลาอันสมควรไม่น้อยกว่า ๓๐ วัน (กรณีผิดสัญญาเรื่องอื่น) หรือไม่น้อยกว่า ๗ วัน (กรณีค้างค่าเช่าติดต่อกัน ๒ งวด) | สัญญาที่ระบุว่าผู้ให้เช่าบอกเลิกสัญญาได้ทันทีโดยไม่ต้องบอกกล่าว ถือว่าขัดต่อประกาศ |
| **๙. การเข้าตรวจสอบห้องพัก (Room Inspection)** | ห้ามผู้ให้เช่าหรือตัวแทนเข้าไปในห้องเช่าโดยไม่แจ้งให้ผู้เช่าทราบล่วงหน้า เว้นแต่มีเหตุฉุกเฉินเร่งด่วนที่อาจก่อให้เกิดความเสียหายร้ายแรง | ข้อสัญญาที่ให้อำนาจผู้ให้เช่าเข้าตรวจห้องพักได้ตลอดเวลาโดยไม่ต้องแจ้ง ขัดต่อกฎหมาย |
| **๑๐. การล็อกห้อง ยึดทรัพย์ ขับไล่ (Self-Help Lockout)** | ห้ามผู้ให้เช่าปิดกั้นทางเข้าออก ใส่กุญแจขัง/ล็อกห้อง ยึดทรัพย์สิน หรือตัดน้ำตัดไฟเพื่อขับไล่ผู้เช่า โดยไม่ผ่านกระบวนการทางกฎหมาย | ข้อสัญญาดังกล่าวเป็นโมฆะ และอาจมีความผิดฐานบุกรุก/กักขังหน่วงเหนี่ยวตามกฎหมายอาญา |
| **๑๑. ค่าต่อสัญญาเช่า (Contract Renewal Fee)** | ห้ามเรียกเก็บค่าต่อสัญญาเช่าฉบับใหม่จากผู้เช่ารายเดิม | ขัดต่อประกาศ ผู้ให้เช่าไม่มีสิทธิเรียกเก็บ |
| **๑๒. ความรับผิดต่อการเสื่อมสภาพตามปกติ (Normal Wear & Tear)** | ห้ามกำหนดให้ผู้เช่าต้องรับผิดชอบในความเสียหายหรือการชำรุดบกพร่องที่เกิดจากการใช้งานตามปกติวิสัย หรือความเสื่อมสภาพตามกาลเวลา | ขัดต่อประกาศ |
